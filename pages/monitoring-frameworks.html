Monitoring Frameworks

We design the indicators, targets and routines that show whether a strategy is being delivered and whether it is working, so that leaders can correct course early. Each framework is sized to the data and the institutions that will run it.

Our Methodology

Results Chain

We map how the strategy is meant to work, from resources and activities to outputs, outcomes and long-term impact, so that every indicator measures a link in the chain rather than activity for its own sake.

Indicators and Targets

We select a small set of indicators with clear definitions, baselines, data sources and owners, and set annual and end-of-period targets that are ambitious but grounded in benchmarks.

Data and Reporting System

We design how data is collected, checked and reported, with templates, dashboards, a reporting calendar and clear roles for each agency, building on the systems the organisation already has wherever possible.

Review and Adjustment

We set up periodic reviews that turn the data into decisions: what is on track, what is not, why, and what changes. Evaluations at key milestones test whether the strategy is achieving its intended impact.
